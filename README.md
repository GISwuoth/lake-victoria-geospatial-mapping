# **Lake Victoria Geospatial Mapping**



\## Overview



This project demonstrates a Python GIS workflow to visualize Lake Victoria using a GeoJSON boundary from Natural Earth.



\## Objectives



\- Load and inspect a GeoJSON boundary using GeoPandas.

\- Examine the coordinate reference system (CRS).

\- Visualize Lake Victoria on an interactive OpenStreetMap basemap.

\- Demonstrate a reproducible Python geospatial mapping workflow.



\## Tools and Libraries



* &#x20;Python
* &#x20;Jupyter Notebook
* &#x20;GeoPandas
* &#x20;Leafmap
* &#x20;Folium



\## Repository Contents



* &#x20;"lake\_victoria.ipynb" — Jupyter Notebook containing the mapping workflow.
* &#x20;"data/" — location for the input GeoJSON file, subject to data licensing.
* &#x20;"outputs/map\_preview.png" — static map preview.
* &#x20;"requirements.txt" — Python dependencies.



\## Data Source



The Lake Victoria boundary was obtained from Natural Earth's Lakes, 1:10 million-scale dataset, distributed as a ZIP archive.

Source: Natural Earth - Downloads

Natural Earth data is in the public domain and can be used and redistributed without permission. Attribution is appreciated.

Scale limitation: The 1:10 million-scale dataset is appropriate for regional visualization and introductory geospatial mapping. It is not intended for detailed shoreline measurements or high-precision local analysis.



\## How to Run



1\. Clone or download this repository.



2\. Install the dependencies:

&#x20;  

&#x20;  "pip install -r requirements.txt"



3\. Place the GeoJSON file at "data/lake\_victoria.geojson".



4\. Open "lake\_victoria.ipynb" in Jupyter Notebook.



5\. Run the cells in order.

\## Limitations



This project demonstrates basic geospatial mapping. Distance-based analyses require a suitable projected coordinate reference system and a justified distance.
